ASMIS (Agricultural Services Management Information System)
An agro services information System that showcase different kind of agricultural services ranging from agricultural machineries, tools, feeds
and consultancy delivery.
The user carries out view and order functionalities, while admins can carry out all CRUD(Create, Read, Update and Delete) functionalities on 
all the services offered across the system.
Their is payment on delivery offering, while on system payment is future enhancement feature.
